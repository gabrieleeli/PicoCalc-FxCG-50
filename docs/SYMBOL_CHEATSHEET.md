# Symbol Cheatsheet app

The launcher now contains a tenth entry, **SYMBOLS / CHEATSHEET**. Open it with
arrow keys and EXE. The app is an offline, read-only reference written entirely
in English.

## Navigation

- **Up / Down:** select one of the six entries on the current page.
- **Left / Right:** move between reference categories (wraps at either end).
- **ESC:** return to the launcher.
- The selected entry's usage/example appears in the lower panel.

## Contents

Fifteen compact pages cover arithmetic, powers and roots, lowercase and
uppercase Greek letters, mathematical constants (including `ln2` and `ln10`), physical constants (including `g0`), common
functions, calculus, sets and logic, statistics, graphing, complex numbers,
matrices, vectors, units, and general notation. All 24 Greek letters are listed
by name in both cases. The app uses short ASCII spellings because the current
5x7 text font is intentionally small and has only a limited set of native
math glyphs.

## Support status

This is a **symbol and notation reference**, not a promise that every listed
notation is accepted by the expression parser. For example, `sqrt`, `cbrt`,
`rootN`, `^`, common trigonometric/logarithmic functions and the aliases
implemented by the math engine can be entered; set theory, calculus and many
physics entries are explanatory notation only until their corresponding
calculator features are implemented. The screen labels this distinction with
"SUPPORT VARIES". The app performs no calculations, network access, dynamic
allocation or background work; its entries are compile-time constant tables.
