# PicoCalc FxCG-50 v1.11.0

Firmware indipendente per la ClockworkPi **PicoCalc**, ispirato alla Casio
fx-CG50, per **Pimoroni Pico Plus 2 W** (scheda principale) e **Raspberry Pi
Pico 2 W**. Questa versione completa **Run-Matrix**: liste 1–26, file CSV,
schermate MatAns/ListAns, editor MAT/VCT con celle esatte e complesse,
modalità Line con INS e ⌟, simboli ingegneristici, Simp, Base-N intera e
comandi grafici.

> ⚠️ **Nessuna prova su hardware fisico.** Il firmware è compilato e verificato
> sul PC (test automatici, sanitizer, simulatore), ma non è ancora stato
> provato su una PicoCalc. Procedura di collaudo:
> [docs/HARDWARE_TEST_v1.11.0.md](https://github.com/gabrieleeli/PicoCalc-FxCG-50/blob/main/docs/HARDWARE_TEST_v1.11.0.md).

## Novità

### Liste e file CSV
- **List 1–26** nei calcoli, in Statistics (26 colonne, SET XList/YList) e in
  GRAPH/TABLE; **sottonomi** delle liste (riga SUB, 8 caratteri).
- **CSV LOAD / SAVE·AS** dall'editor delle liste (OPTN) e dall'editor
  MAT/VCT (F4), su microSD o flash interna, con scrittura atomica;
  separatore `,`/`;` e simbolo decimale `.`/`,` configurabili.

### Run-Matrix
- **Schermate MatAns / VctAns / ListAns** per i risultati oltre 6×6 (o 20
  elementi), scorrevoli, con la cella corrente.
- **Editor MAT/VCT**: celle con espressioni e forme esatte (`1/3`, `2√3`,
  `π/4`) e numeri complessi; colonne oltre le 4 visibili scorrevoli con la
  posizione `r c`; le memorie conservano le forme esatte.
- **Modalità Line**: INS (sovrascrittura), frazioni `⌟` (`2⌟3`, `1⌟2⌟3`) in
  input e nei risultati, risultati più lunghi della riga scorrevoli.
- **SHIFT+INS** in Math: il valore a destra del cursore diventa l'argomento
  del modello (`1+(2+3)+4` → `1+√(2+3)+4`).
- **Simboli ingegneristici** m µ n p f k M G T e display **Eng** con i
  simboli (`999k+25k` = `1.024M`).
- **▶Simp** con e senza fattore (`15/60▶Simp` → `5/20  F=3`), Simplify
  Auto/Manual.
- **Base-N intera** (SET UP › Mode: Dec, Hex, Bin, Oct): interi a 32 bit in
  complemento a due, **And, Or, Xor, Xnor, Not, Neg**, prefissi d h b o.
- **Comandi grafici** (OPTN › SKETCH): Cls, ViewWindow, Graph Y=/r=/X=/(X,Y)=,
  Plot, PlotOn/Off/Chg, Line, F-Line, Circle, Vertical, Horizontal, Text,
  PxlOn/Off/Chg, Tangent, Normal, Inverse; disegnati nella schermata di GRAPH,
  EXIT torna ai calcoli.

## Miglioramenti
- Record del workspace **versione 7**: i dati delle versioni 1.6.0–1.10.0 si
  aggiornano senza perdite (provato con un record generato dalla v1.10.0).
- Statistics: SET XList/YList, CSV, DEL-ALL; MEMORY: liste e sottonomi.
- SET UP: Mode, Simplify, CSV Separator, CSV Decimal.

## Comportamenti cambiati
- In Line il tasto frazione scrive `⌟` (come la fx-CG50); la divisione resta `/`.
- Display Eng: simboli ingegneristici al posto di ×10ⁿ tra 10⁻¹⁵ e 10¹².

## Compatibilità hardware

| | Pimoroni Pico Plus 2 W | Raspberry Pi Pico 2 W |
|---|---|---|
| File | `picocalc_fxai_pico_plus_2w-v1.11.0.uf2` | `picocalc_fxai_pico2w-v1.11.0.uf2` |
| Liste (per lista / tutte le 26) | 999 / 20 000 elementi | 255 / 1 530 |
| Matrici (lato / elementi per matrice / in tutto) | 999 / 10 000 / 20 000 | 40 / 400 / 1 200 |
| Cronologia | 200 righe | 40 |

Gli UF2 **non sono intercambiabili**. Pin della PicoCalc, driver, mappa della
flash e script del linker sono invariati rispetto alla v1.10.0.

## Limitazioni note
- Nessuna prova su hardware fisico.
- Comandi grafici: sottoinsieme (mancano PxlTest(, DrawStat, StoPict/RclPict,
  stili, disequazioni, G∫dx); i grafici dei comandi non vanno nei progetti.
- Liste: niente List File 1–6 né `List "nome"` nei calcoli.
- Simplify Manual lascia non ridotta solo la frazione digitata.
- Base-N: variabili A–F non raggiungibili in Hex.
